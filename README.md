# 🌡️ Conversor de Temperatura (Temperature Converter)

> Uma aplicação web prática e precisa desenvolvida para realizar a conversão instantânea de valores de temperatura entre as escalas Celsius (°C), Fahrenheit (°F) e Kelvin (K).

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco na aplicação de **JavaScript moderno (ES6+)**, fórmulas de conversão matemática, validação de dados e manipulação dinâmica do DOM. A aplicação permite alternar entre diferentes unidades de medida de forma simples, fornecendo resultados exatos e formatados.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica da interface e campos de entrada de dados.
* **CSS3:** Estilização visual, layouts centralizados e design responsivo.
* **JavaScript (ES6+):** Lógica matemática com fórmulas de conversão térmica, tratamento de eventos e atualização dinâmica do DOM.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Múltiplas Escalas:** Conversão bidirecional entre Celsius, Fahrenheit e Kelvin.
* **Cálculo Instantâneo:** Atualização dinâmica dos resultados na tela à medida que o usuário interage.
* **Validação de Entradas:** Tratamento para evitar entradas inválidas ou vazias.
* **Interface Responsiva:** Design adaptado para uso em dispositivos móveis e computadores.
